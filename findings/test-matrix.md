## 关键推论链

```
写入返回 16
  → 设备必须回 ACK（USB 2.0 规范）
  → 设备 USB 控制器与 PHY 双向正常        【观测→推导】
  → 排除硬件故障

端点 GET_STATUS = 0x0000
  → 端点未被 HALT
  → 排除端点卡死                          【观测】

厂商客户端（型号匹配）也失败
  → 排除我方软件/驱动/协议实现错误        【观测→推导】

厂商控制请求返回"长度跟随+全零"
  → 固件用桩应答应付未实现请求
  → 排除 Ambarella boot 模式              【观测→推导】

设备屏幕只显示 USB 图标、无模式菜单
  → 固件识别到 USB 连接，但未进入数据模式 【观测】

设备能正常录放
  → 存储与主控固件正常，仅 USB 数据服务异常 【观测】
```
